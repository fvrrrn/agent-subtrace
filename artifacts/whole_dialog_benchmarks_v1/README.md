Authoritative context: [../../../AGENTS.md](../../../AGENTS.md), §7.19.

Five fixed models:
- frozen linear: validation-BCE-selected epoch2;
- frozen linear + unsafe ranking: validation-BCE-selected epoch2;
- LoRA linear: **exactly epoch1**, locked before epoch2 could replace selection;
- LoRA linear + unsafe ranking: **exactly epoch1**, likewise locked;
- original pinned Kev-4B, shipped weights and temperature, no fine-tuning.

Every head/adapter/config file was hash-checked before/after copying. This
evaluation does not change or stop training. At the user's request,
scheduler964648 evaluates concurrently with training on GPU2, sequentially by
model. It replaces the initial idle waiter932450; that waiter's SIGINT is not an
evaluation failure. GPU2 had47335MiB free at admission. Before each model at least
32768MiB must be free, otherwise wait for training via pidfd without polling.
Largest cases run first; the first OOM stops the queue rather than generating
mass exclusions. Teachers and other users' processes are unchanged. No extra
models, threshold fitting or automatic retries.
