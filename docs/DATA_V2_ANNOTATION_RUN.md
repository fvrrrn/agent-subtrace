# Data v2: журнал разметки пула

Запуск silver-разметки кандидатов судьёй `v3a` на Qwen3.8-Flash-Next-FP8.

## Условия

| Параметр | Значение |
|---|---|
| Модель | `qwen3.8-flash-next`, FP8, TP4 + EP4 |
| Промпт | `prompts/v3a.txt` (выбран в `DATA_V2_PROMPT_TUNING.md`) |
| Декодирование | temperature 0.0, guided JSON, max_tokens 768 |
| Concurrency | 32 |
| Хост | `llm02`, 4× H100 PCIe, `GPU_UTIL=0.90`, `MAX_SEQS=96` |
| Выход | `annotations_v3a_full.jsonl` |

Судья видит только `state`: `tool_interfaces`, `user_request`,
`observed_history`, `proposed_action`. Метки, `provenance`, `sources` и
`split` в промпт не попадают (проверено: у всех 157 422 строк `state`
содержит ровно эти четыре ключа).

## Решение об исключении AgentDoG

AgentDoG — OOD-источник, в train по спеке не идёт. Разметка уровня действия
в нём отсутствует: `source_label` = null у всех строк, а `trajectory_label`
помечен как `label_quality: trajectory_label_not_broadcast`, то есть метка
траектории сознательно не транслируется на действия (иначе это hindsight-
разметка, как у StepSafe).

Поэтому из очереди исключены **все 24 332 строки, у которых `sources`
содержит `AgentDoG`** — и чистые AgentDoG (20 442), и двойные
AgentDoG + StepSafe (3 890): у двойных ключ тоже начинается с `AgentDoG`,
это те же OOD-траектории с дополнительной action-меткой от StepSafe.

| | Строк |
|---|---|
| Исходный пул | 157 422 |
| Исключено AgentDoG | 24 332 |
| Осталось в очереди | 133 090 |
| Уже размечено до исключения, всего | 2 425 |
| из них AgentDoG | **457 — оставлены** |
| из них не-AgentDoG | 1 968 |

### Уже размеченные AgentDoG оставлены

457 кейсов AgentDoG были размечены до исключения и **сохраняются в выходном
файле**. Это частичная OOD-выборка: она позволяет проверить, находит ли
action-level разметка unsafe-действие внутри траекторий, помеченных
`trajectory_label = unsafe`, не тратя время на все 24 332.

Как их найти:

```python
"AgentDoG" in row["sources"]
```

Ограничение: 457 кейсов — это неполная и нестратифицированная подвыборка
(около 1.9% от 24 332). Для отчётной OOD-оценки её недостаточно; при
необходимости добирается отдельным прогоном на стратифицированной выборке.

**Эти строки не должны попадать в train.** Как и 125 gold-кейсов, они
отфильтровываются при сборке датасета: AgentDoG — по `sources`, gold — по
списку ключей.

## Почему переехали с dsswat27

На `dsswat27` освобождали карты для другого пользователя. Прогресс (745
кейсов) перенесён на `llm02`, разметка продолжена с того же места по ключам,
без повторной обработки готовых строк.

## Остаточные ограничения

- Прогресс переносился дважды (dsswat27 → llm02, затем фильтрация AgentDoG),
  поэтому в выходном файле остаётся 457 AgentDoG-строк, размеченных до
  решения об исключении.
- Разметка silver, не gold. Калибровка на human-gold ещё не делалась.
